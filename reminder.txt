HERE ARE THE MAIN COMMANDS FOR VENV
    - To create the venv: python -m venv venv     
    - To run the venv: .\venv\Scripts\Activate.ps1 or venv\Scripts\activate.bat
    - To create the requirements file that contains the module i'll have to download: pip freeze > requirements
    - To install the modules inside the requirements: pip install -r requirements.txt

TO RUN GIT PROPERLY ON GITHUB (no file empty)
    - Create a new repository on GitHub, copy the url
    - Connect your local folder to GitHub: git remote add origin https://github.com/yourusername/BILAN_ESSAIE.git
    - Verification run:  git remote -v in PowerShell—your GitHub URL will appear next to origin (fetch) and origin (push).
    - Rename your branch to main and push your code: git branch -M main,
                                                    git push -u origin main
